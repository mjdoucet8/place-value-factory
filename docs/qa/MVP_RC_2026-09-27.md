# Functional MVP release candidate — 27 September 2026

## Outcome

The current uncommitted product history plus the reference-style factory redesign form a verified local fictional-data MVP release candidate. No existing development record was reset or imported into the checks.

## Functional pilot

`npm run pilot:local` created a new isolated PostgreSQL 16 cluster and private credentials under `/tmp`. The four-test pilot suite passed. Its principal journey created a teacher-owned class, issued fictional student access, completed five orders, recovered replies lost before and after commit, preserved results across reload, displayed exact teacher evidence, completed practice, rejected a revoked student's queued save, archived the class and preserved authorized evidence. The same run checked the gallery, major compositions, assets and map behavior.

## Defects found and repaired

The first full browser regression correctly rejected two colors introduced by the factory redesign. The Ship button's lightest green produced 3.62:1 against white, and translucent denomination-label backing exposed text directly to artwork. The Ship gradient is now darker, machine labels use opaque navy, and the current-order card has an explicit high-contrast foreground and fallback background. The focused audit then found no low-contrast or directly image-backed visible text in any of its 26 student, teacher and fixture states.

## Staging package

The new provider-independent container package builds and serves the SPA and API on one origin. It binds through `HOST`, exposes `/api/healthz`, runs forward migrations, and provisions at most one fictional teacher from host-held secrets without logging the password. It requires the explicit staging guard (`PVF_MODE=staging`, `PVF_AUTH=local`, `PVF_FICTIONAL_ONLY=true`) and an HTTPS origin. Production continues to fail closed pending the school identity adapter.

The static/health runtime and pilot/staging deployment validator have focused passing tests. A local image build was not run because neither Docker nor Podman is installed on this machine.

## External launch boundary

The Git remote points to the owner's GitHub repository, but the saved GitHub CLI credential is invalid. No Vercel, Fly, Railway, Render, Docker or Podman command is installed or connected. Consequently, no remote repository, database or hosting service was changed. Launch now needs a connected private hosting account, approved region and HTTPS origin. Real-student production additionally needs the school identity adapter and school policy decisions recorded in `docs/DEPLOYMENT_READINESS.md`.
