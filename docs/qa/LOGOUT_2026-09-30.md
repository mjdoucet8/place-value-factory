# Settings removal and logout — 30 September 2026

The map header replaces Settings with Log out. The Settings screen, screen type, navigation, save handler and component are removed. Old Settings URLs resolve through the map fallback. Existing stored preferences and their API remain compatible.

Logout uses DELETE /api/v1/auth/session, waits for success, clears private in-memory screens and credentials, and replaces the current URL with /student/login. Back navigation cannot expose a signed-out screen. Map actions are disabled while logout is pending; a failed request leaves a clear retry message. Draft storage, pending shipments, saved missions, stars and server preferences are retained. The development adapter now expires its cookie, while secure mode still revokes the server session under the existing origin/CSRF requirements. An already-ended session returns 204 so logout can be retried after a lost response.
